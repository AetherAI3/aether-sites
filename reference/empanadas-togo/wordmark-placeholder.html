Implementation and replacement

Reuse the .wordmark component and its three CSS selectors. This file is the editable source; open it directly in a browser. There is no JavaScript requirement. The script appearance depends on installed fonts. If none are available, an italic serif displays instead—do not describe that as the original sign font.

For production, replace the span with the owner's original SVG or high-resolution transparent logo, preserve its aspect ratio, and retain accessible alternative text. Confirm spelling, asset ownership, and final visual approval with the owner. No trademark clearance is implied.
