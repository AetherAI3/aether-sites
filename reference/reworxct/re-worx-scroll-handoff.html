02 / Motion principles

Everything is slow, heavy and one-directional — the brand is mass, not spring. Entrances settle (0.9–1.4s, var(--mot-ease)), never bounce. Ambient loops breathe on 20–40s cycles. One idea moves per viewport: if the media drifts, the type is still. All motion is CSS-first and collapses to fully visible static content under prefers-reduced-motion.

Wiring pattern (drop-in)

<div class="video-bg kb-frame">
  <video autoplay muted loop playsinline preload="metadata"
         poster="<matching-still.png>" class="video-bg--dim">
    <source src="<clip.mp4>" type="video/mp4">
  </video>
  <div class="video-scrim"></div>
  <!-- section content -->
</div>

<script>
// play only in view; honor reduced motion
const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
document.querySelectorAll('.video-bg video').forEach(v => {
  if (reduce) { v.removeAttribute('autoplay'); v.pause(); return; }
  new IntersectionObserver(([e]) =>
    e.isIntersecting ? v.play() : v.pause(), {threshold: .15}).observe(v);
});
</script>

Poster = the matching still, so first paint is instant and the motion fades in from an identical frame. Keep loops under ~3 MB via 720p for bands; only the hero justifies 1080p.
